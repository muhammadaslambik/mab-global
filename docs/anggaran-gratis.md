# Anggaran tahap awal (gratis)

Angka batas gratis sering berubah. Cek ulang di dokumentasi resmi sebelum bergantung padanya.

- Cloudflare Workers gratis: permintaan harian terbatas, 5 pemicu terjadwal per akun.
- Supabase gratis: proyek dijeda setelah sekitar seminggu tanpa aktivitas, tidak ada backup otomatis.
- LLM gratis tidak tak terbatas, dan sebagian tier gratis mengecualikan penggunaan komersial atau memakai data untuk pelatihan.
- Jangan kirim data pelanggan atau rahasia ke tier gratis.
