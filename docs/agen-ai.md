# Agen AI

Alur tugas: validasi -> penjaga (auth, batas laju) -> persetujuan manusia bila berisiko -> LLM -> simpan hasil.

Kepala bidang (tahap berikut): rencana (pilih 2-6 anggota) -> anggota mengerjakan -> kepala menggabungkan.
Kategori berisiko yang wajib persetujuan: publish, finance, customer-reply, store-order.
Agen tidak boleh mengklaim sudah memposting atau mengakses data real-time kalau tool-nya belum ada.
